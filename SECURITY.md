# Reportando uma vulnerabilidade

Não publique detalhes exploráveis em issues públicas. Use GitHub Security Advisories privados do repositório para enviar uma descrição, impacto, reprodução mínima e versão/commit afetado. Se o recurso privado não estiver habilitado, abra uma issue sem detalhes e peça um canal privado aos mantenedores.

Não envie credenciais, dados de produção, dumps, tokens, ou dados pessoais. A equipe deve confirmar recebimento, reproduzir em ambiente isolado, corrigir e coordenar divulgação responsável. Não há SLA de resposta publicado neste momento.

## Escopo

Aplicação web/API, workers, adaptadores, autenticação/configuração e workflows deste repositório. Conteúdo ou disponibilidade de sites oficiais de terceiros deve ser reportado aos respectivos operadores. Não teste produção sem autorização explícita.
