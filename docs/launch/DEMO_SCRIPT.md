# Roteiro de demo — 25–30 segundos

1. **0–3s:** abrir a home; apontar “Entenda como uma lei chegou ao texto atual”.
2. **3–6s:** clicar em “Veja o antes e depois de um artigo”.
3. **6–10s:** mostrar Código Civil, art. 389, Lei 14.905/2024 e a data registrada.
4. **10–18s:** ler os dois textos; destacar a retirada de “segundo índices oficiais regularmente estabelecidos”.
5. **18–23s:** abrir a versão do trecho no Normas.leg.br e apontar o aviso “valor jurídico não oficial”.
6. **23–27s:** mostrar o link separado para o texto consolidado consultado e o status “Comparação registrada”.
7. **27–30s:** fechar no GitHub e convite para adapters e fixtures.

O registro do Normas.leg.br não é apresentado como fonte primária, e a data registrada não é chamada de vigência. Para mostrar uma inclusão com publicação primária, use o caso complementar da Lei Maria da Penha documentado em `HERO_CASE.md`.

Para screenshot/regravação: `docs/assets/launch/record-demo.mjs`. Usar uma janela sem extensões ou dados pessoais. Não editar a evidência nem esconder a ressalva da fonte.
