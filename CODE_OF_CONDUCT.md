# Código de conduta

Participantes devem tratar pessoas com respeito e manter as discussões técnicas focadas em evidência, impacto e alternativas. Assédio, discriminação, ameaças, doxxing, insultos direcionados ou publicação de informação privada não são aceitos.

Mantenedores podem editar ou remover conteúdo que viole estas regras e restringir participação conforme a gravidade. Para relatar uma ocorrência, use GitHub Security Advisories privados; para questões não sensíveis, abra issue de moderação sem expor dados pessoais.
